# PENDANAAN

Portal Pendanaan Sosial Pemkab Tulungagung. Laravel 13, PHP 8.3+, Blade/Tailwind/Vite, PostgreSQL/Supabase target.

Baca AGENTS.md, ARCHITECTURE.md, PRD, dan docs sebelum coding. Jalankan `composer install`, `cp .env.example .env`, `php artisan key:generate`, `php artisan serve`. Jangan commit credential. Integrasi eksternal yang belum resmi adalah Planned/Simulation.
