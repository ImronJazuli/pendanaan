# Use Case

## Admin Pemkab
Kelola instansi, verifikasi kausa, verifikasi laporan, publikasi transparansi, audit.

## Instansi/OPD
Kelola profil, ajukan kausa, lihat status/catatan, unggah laporan.

## Masyarakat/Donatur
Registrasi/login, katalog, detail, donasi, status/riwayat, transparansi.

Out of scope: permohonan bantuan dan pengaduan.
